# بوت لعبة التمرير 🔤 (Telegram)

لعبة سلسلة كلمات جماعية بالمجموعات: كل لاعب يكتب كلمة تبدأ بـ**آخر حرف** من كلمة اللاعب الي قبله، والوقت يقل كل شوية، والي يخلص وقته يطلع. آخر واحد يضل هو الفائز 🏆

## المميزات
- **صور مولدة تلقائياً**: ترتيب اللاعبين، بطاقة الدور (الاسم + الصورة + الوقت + الحرف)، وصورة الفائز. الصور والأسماء تنسحب من حسابات تيليجرام.
- **فحص الكلمات مجاناً** بقاموس عربي مدمج (~120 ألف كلمة) يشتغل بدون إنترنت وبلحظة. ومالك البوت يكدر يضيف كلمات ناقصة (مثل الكلمات العراقية) أو يمنع كلمات.
- فحص إضافي بالذكاء الاصطناعي (Claude) **اختياري ومدفوع** للكلمات الي مو بالقاموس.
- **مستويات**: 12 ثانية ← 8 ← 4، والوقت ينزل كل 6 أسئلة.
- **إحصائيات** لكل لاعب: عدد الجولات، مرات الفوز، الكلمات، متوسط السرعة، أسرع إجابة، مرات الإقصاء، الترتيب.
- جولة وحدة لكل مجموعة، ويكدر البوت يشغّل جولات بأكثر من مجموعة بنفس الوقت.

## الأوامر
| وين | الأمر | الوظيفة |
|---|---|---|
| الخاص | `/start` | رسالة ترحيب + زر إضافة البوت للمجموعة كمشرف |
| الخاص | `/help` | شرح اللعبة |
| المجموعة | `جولة` | بدء جولة جديدة (أو إعادة نشرها إذا بعدها ما بدأت) |
| المجموعة | `احصائياتي` أو `/stats` | إحصائياتك |
| المجموعة | `المتصدرين` | أفضل 10 لاعبين |
| المجموعة | `ايقاف` | إيقاف الجولة (لصاحبها أو المشرفين) |
| أي مكان | `افحص كلمة طماطة` | تشوف الكلمة مقبولة لو لا |
| أي مكان | `اضف كلمة طماطة` | إضافة كلمة للقاموس (لمالك البوت فقط) |
| أي مكان | `احذف كلمة ...` | منع كلمة (لمالك البوت فقط) |

أزرار الجولة: **انضمام** و**مغادرة** للكل، و**بدء** و**إعادة النشر** لصاحب الجولة فقط.

## قواعد الحروف
- كل أشكال الهمزة (أ إ آ ء ؤ ئ) تنحسب **أ**.
- **ة** تنحسب **ه**، و**ى** تنحسب **ي**.
- الحركات والتطويل (ـ) تنشال تلقائياً.
- الكلمة ما تتكرر بنفس الجولة.
- ردود فعل البوت على رسالتك: ⚡/👍 كلمة صحيحة، 👎 كلمة غلط أو بحرف غلط (تكدر تحاول مرة ثانية ضمن الوقت)، 🤔 الكلمة مستخدمة قبل.

## التشغيل
المتطلبات: Node.js 20 أو أحدث، وقاعدة MongoDB (محلية أو Atlas).

```bash
npm install
cp .env.example .env   # واملأ القيم
npm run dev            # للتطوير
# أو للإنتاج:
npm run build && npm start
```

### متغيرات البيئة
| المتغير | الوصف |
|---|---|
| `BOT_TOKEN` | توكن البوت من @BotFather (**مطلوب**) |
| `MONGODB_URI` / `MONGODB_DB` | رابط واسم قاعدة البيانات (**مطلوب**) |
| `BOT_ADMIN_IDS` | رقم حسابك بتيليجرام (من @userinfobot) علمود تكدر تضيف وتحذف كلمات |
| `BRAND_NAME` | الاسم الي يطلع أسفل الصور |
| `MIN_PLAYERS` / `MAX_PLAYERS` / `TURNS_PER_LEVEL` | إعدادات اللعبة |
| `ANTHROPIC_API_KEY` / `AI_MODEL` | اختياري ومدفوع: فحص بالذكاء الاصطناعي للكلمات الي مو بالقاموس |

## النشر مجاناً (Render + MongoDB Atlas)
1. **القاعدة:** بـ [MongoDB Atlas](https://www.mongodb.com/atlas) سوّي Cluster مجاني (M0)، وبـ Network Access ضيف `0.0.0.0/0`، وانسخ رابط الاتصال.
2. **الاستضافة:** بـ [render.com](https://render.com) اختار **New ← Web Service** واربطه بالمستودع، واختار الخطة **Free**:
   - Build Command: `npm install && npm run build`
   - Start Command: `npm start`
   - وحط المتغيرات أعلاه بـ Environment.
3. **خليه صاحي:** خدمة Render المجانية تنام إذا ما وصلها طلب لمدة 15 دقيقة. سوّي حساب مجاني بـ [UptimeRobot](https://uptimerobot.com) وضيف Monitor من نوع HTTP على رابط خدمتك (`https://اسم-خدمتك.onrender.com`) كل 5 دقايق.

### إعداد البوت بـ BotFather
البوت لازم يشوف رسائل المجموعة علمود يقرأ الكلمات. يعني إما ترفعه **مشرف** (زر الإضافة بأمر `/start` يطلب صلاحية الإشراف تلقائياً)، أو تطفي **Group Privacy** من BotFather ← Bot Settings.

### معاينة التصاميم
```bash
npm run preview   # يولد صور تجريبية بمجلد preview/
```
